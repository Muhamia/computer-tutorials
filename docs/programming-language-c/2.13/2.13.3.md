### 2.13.3 二分查找

二分查找是一种查找数据的算法

#### 构思

我们先回忆、思考一下

如果我们要从一个数组中查找某一个特定的数据

那么我们该怎么办?

很简单，我们之前学过遍历

是的，遍历确实是一种方法，而且它是十分简单的方法

但是，我们想一下就知道，这个算法的时间复杂度是 `O(n)`

也就是说，如果我们有一个长度为10000的数组，那么最悲观的情况就是我们要把10000个元素全遍历一遍

而且如果我们有很多个10000长度的数组，每一个都这么干的话，那所需要的时间就太长了

所以，这里我们引出二分查找

#### 算法思路概述

首先，二分查找有一个应用前提，就是当前的这个数组是按照一定顺序的

可以从小到大，也可以从大到小

总之需要满足单调递增或单调递减

这里我们就先假设是单调递增，也就是从小到大

好了，那么，我们可以从中间开始，找一个中间或者靠近中间的数

如果发现中间的元素比我们要找小，那么我们就看左半部分，并再从左半部分的中间开始

之后，我们不断从中间查找，并向两边走，然后再找中间......如此往复，我们一定可以找到我们要找的数据

当然，前提是这个数据存在

#### 代码示例

二分查找的C语言代码示例如下

```C
#define _CRT_SECURE_NO_WARNINGS

#include <stdio.h>
#include <stdlib.h>
#include <stddef.h>

int search(int arr[], int len, int target)//如果找到了，返回对应的下标/索引。如果没找到返回-1
{
	int left = 0;//定义查找范围的左边界
	int right = len - 1;//右边界

	while (left <= right)
	{
		int mid = (left+right) / 2;//设定靠中间的数对应的下标
		if (arr[mid] == target)
		{
			return mid;
		}
		else if (arr[mid] < target)
		{
			left = mid + 1;//反正Mid这个位置肯定不是了，我们往后偏移一个位置也没问题
		}
		else
		{
			right = mid - 1;
		}
	}

	return -1;//-1表示没找到
}

int main()
{
	int arr[5] = { 2,4,5,19,30 };

	int location = search(arr, (sizeof(arr) / sizeof(int)), 4);
	printf("%d\n", location);
	location = search(arr, sizeof(arr) / sizeof(int), 3);
	printf("%d\n", location);
	return 0;
}
```
