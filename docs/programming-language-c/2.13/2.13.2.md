### 2.13.2 冒泡排序

#### 构思

我们思考一下，现在我们有一个数组，里面的数组无序摆放

现在我们希望这个数组里面的数据单调递增，那么我们该怎么做?

或许我们重复一些方法，使得数据之间进行比较，把大的数往后排，小的数字往后排。从而实现这个结果

#### 算法概述

冒泡排序，就是从第一个数开始比较，遇到小的就往后排，遇到大的，我们就聚焦下一位这个大的数字

比如说，一个数组里的第一个数字是10

那么我就先将10和第二个数比较

如果第二个数是8，那么10和8互换

之后，如果第三个数是19，比10大

那么我们就先聚焦19，让19和后面的数字比较，进行和上面类似的过程

这样一来，最大的数字就会排到最后，我们就不用管最后一位了

之后，我们再排序第二个大的......直到我们全部排序好

当然，我们也可以加一个检查点，检查我们看过一轮后，有没有发生互换

如果没有发生互换，其实也就排好了，后面的元素也就不用管了

#### 代码示例
```C
void bubbleSort(int arr[], int len)
{
	int remain = len;

	while (remain != 1)//待排序变量只剩1个的时候，其实也就排序好了
	{
		int location = 0;
		int check = 0;

		while (location < remain - 1)
		{
			if (arr[location] <= arr[location + 1])//不用变，聚焦下一个数
			{
				location++;
			}
			else//执行互换
			{
				check = 1;

				int temp = arr[location];
				arr[location] = arr[location + 1];
				arr[location + 1] = temp;

				location++;//聚焦点跟着移动
			}
		}
		if (check == 0)
		{
			return;
		}

		remain--;
	}

	return;
}

int main()
{
	int arr[5] = { 2,40,24,19,30 };

	bubbleSort(arr, 5);

	for (int i = 0;i < 5;i++)
	{
		printf("%d\n", arr[i]);
	}
	return 0;
}
```
