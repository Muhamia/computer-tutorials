### 2.10.1 字符串的定义

先简单说一下什么是字符串
字符串，就是一大串字符(也可以是中文、特殊符号)排列在一起组合成的一个整体
比如"Hello, World!"就是一个字符串、"木合猫猫是世界上最可爱的猫娘"也是一个字符串

### 数组形式定义
一般来讲，我们也更常用这种方法
因为这个方法定义出来的字符串是可写的
#### 定义格式和注意点
定义格式
```C
char 名字[长度] = "内容";
```

值得注意的是，由于C语言中，需要在字符串末尾加上'\0'表示一个字符串的结束

而'\0'会自动添加

所以一般来讲，我们定义的长度一般会比预期长度多一点
例如
```c
char greeting[15] = "hello, world!";
```

一般来讲，我们多占几个字节也是没问题的
像上面这个例子，我们用15个可以，20个也可以
只要别太多，上来申请个1000字节的雷霆大数组就为了存一个"hello, world!"就行

#### 操作方法

我们说过，这种字符串是可写的
我们只需要像平常数组一样，直接写索引然后改就可以了
例如
```c
greeting[0] = 'H';

```




#### 指针形式定义
字符串在内存中存储方式类似数组
即首个单字符的地址就是字符串的地址
所以可以定义一个指针，指向第一个单字符
