### 2.10.2 字符串的输入输出

#### 输入
我们之前说过，只有数组定义的字符串是可写的
所以我们只能考虑数组定义的字符串

这里我们需要scanf用%s来写入字符串

示例
```C
char str[20];
scanf("%s", str);
```

这样，我们就可以把输入的内容输入到str中



#### 输出
##### 数组形式定义
字符串的格式化输出符号为%s
输出示例
```c
printf("%s\n",str);
```

##### 指针形式定义
输出的时候，直接%s然后直接输入指针名就可以
例如
```C
char *p = "abcde";
printf("%s\n",p);
```
