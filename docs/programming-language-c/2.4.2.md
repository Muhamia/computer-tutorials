### 2.4.2 一维数组

#### 数组的创建

数据类型 数组名[大小]

举个例子
```C
int arr[10];
```

创建一个名称为arr，可以存储10个int类型数据的数组

#### 数组元素的引用

数组中的每个元素都可以通过其对应的索引来调用

索引是**从0开始排的**
也就是说，第一个元素的索引也就是0，也就是arr[0]

所以，arr[i] (i为对应索引) 就可以指代第i-1个元素

实例1：创建一个存储数据为从1到10的数组
```C
int arr[10];

for (int i = 0;i < 10;i++)
{
	arr[i] = i + 1; //赋值
}
```

实例2：遍历(把数组中所有数组都过一遍)我们刚才创建的数组
```C
for (int i = 0;i < 10;i++)
{
	printf("%d\n", arr[i]);
}
```
