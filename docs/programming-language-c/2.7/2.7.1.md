#### 指针的直观认识

##### 什么是指针?

其实最直观、通俗来说:
我们现在创建一个变量，这个变量的地址就是指针

对，地址就是指针

先这么理解

##### 指针变量

好，现在有一个类型的变量，赋值就是赋的地址
这个变量就是指针变量

指针变量的定义:
```C

int a = 10;
int* p = &a;

```
就是多了一个取地址符（取的是变量的地址）和一个星号

像上面这样，我们就创建了一个int指针类型的指针变量，其值是a的地址
也可以说int指针 p 指向 a

指针变量的特点:
1.指针变量取谁的地址，就指向谁
2.指针可以根据地址去获取变量，比如:
```C
int* p = &a;
int c = *p;
```

这样变量c的值就是10
这里星号就发挥了一个取内容的作用
