### 2.6.1 什么是函数

#### 函数的概念理解

##### 一般化的理解
函数，我们在中学的时候都接触过这个词

例如，三角函数
我们以y = sinx举例，我们输入的值为x，输出的值为y，也就是sinx

比如，我们让x = π/2，那么我们就会得到输出的值y = 1

所以说，函数，就是一个按照输入的值，给出输出值的机器

至于输入的值和输出的值有什么关系，就是这个机器的自身性质了，也就是我们最关心的部分，也是我们要编写的部分

##### 在C语言中的概念

我们知道，函数是一个通过输入给出输出的机器

那么，我们可不可以让这个机器，完成我们程序中的一部分功能呢?

答案是肯定的

我们可以编写函数，将我们程序中的一个功能封装为一个模块，从而简化我们的程序结构，大大增加可读性

例如，我现在要做一个贪吃蛇的游戏
那么我们可以把蛇的移动、蛇的碰撞判断、地图上食物的生成这些功能分别封装进函数里，从而形成一个个模块
最后在实现游戏时，我们只需要把这些模块拼凑起来即可


#### 重新认识main函数

我们知道，每次开始编写一个C语言程序的时候，都会先写一个
```c
int main()
{
    ...

    return 0;
}

```

而这个main，本身也是一个函数

它是C语言程序在开始时就直接执行的一个函数

所以，我们的程序最终都要在main函数里实现

但事实上，如果我们把main函数写得像懒婆娘的裹脚一样——又臭又长，那肯定是不好的

因此，我们就可以像上面说的那样，把程序的功能进行分装
最后，我们只要在main函数里对各个模块函数进行调用，实现我们的程序即可


#### 重新认识printf和scanf

其实，printf和scanf本质上讲也是函数

定义格式分别为
int printf(const char *format, ...);
int scanf(const char *format, ...);

只不过， `printf` 函数的返回值几乎无人关心，而我们的教程为了简化，也不关心 `scanf` 的返回值。把他们当一个方便的工具来使用

事实上，这也正是函数的意义:把复杂的工作包装为一个简单易用的函数，使一些复杂的工作执行起来十分方便
