### 2.9.2 函数指针与指针函数

这里与前面的命名规则类似

函数指针，就是一个指向函数的指针

指针函数，就是返回值类型为指针的函数

#### 函数指针
我认为这并不是很实用  
我写教程的时候甚至都愣了一下  
我上大一这一年就没有用过这东西  
所以这里就简单介绍一下
**我觉得你跳过这一部分都没问题**

定义格式:
返回值类型* (指针名)(形参列表) = 函数名


比如
```C
int A()
{
	printf("调用了A函数");
}
void main()
{
	int (*p)() = A;  //定义
	p(); //调用
}


```

而调用的话，就直接 指针名+形参括号 就可以了
还有一种调用方法
(*p)();
就是加个星号取内容，并且不要忘了加括号
不过我认为这样更麻烦


#### 指针函数
指针函数，就是返回值为指针类型的函数

这类函数，相比于函数指针就常用许多了

比如说，我们要在函数内创建一段内容，并且我们希望这段内容可以保留下来共其他函数调用，而不是随着函数的生命周期结束而结束

那么，我们就可以在函数内malloc一段内存，然后再返回这一段内存的地址
