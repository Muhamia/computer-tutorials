### 队列

#### 什么是队列?

队列是一种和栈相似的数据结构

我们说过，栈是先进后出的数据结构

而队列就是先进先出的数据结构

就像超市排队一样，先开始排队的人先结账，先回家

#### 实现方式

同样的，我们能轻松想到用数组和队列实现

第一种，如果是链表，我们就需要准备一个头删节点、一个尾增节点的函数

第二种，如果是数组模拟，我们就需要准备两个“模拟指针”

对，就是用两个数字来表示我们当前队列的头和尾

```C
int queue[50];//这个50表示了一个队列最多能容纳的数据
int qhead, qtail;

qhead = 0;
qtail = qhead;

//如果要在队尾添加一个数据
int data = 10;
queue[qtail] = data;
qtail = (qtail + 1) % 50;
//这里取50的余数，是因为当我们的数据达到第50位的时候，qtail会自动归位到0的位置
//当然，我们规定了这个队列最多容纳的就是50个数据，因此这个时候queue[0]的数据会被覆盖，也就是被我们舍弃掉了


//如果我们要让队首的一个数据出去
int getData = queue[qhead];//也可以不接收数据，根据实际情况决定
qhead = (qhead + 1) % 50;
```

#### 一个实际例子

我们都听说过寻路算法

现在我们假设用一个 `20*20` 大小的二维数组来表示一块地图，上面还有一些障碍

现在我们要通过一个寻路算法，计算出从当前地点到目的地的最短距离

这就我们从当前出发，找到目的地，再记录下来我们走过了多少步

```C
//全局变量部分
const int fdc[4][2] = { {1 ,0},{-1,0},{0,1},{0,-1} };//用来四向检查的数组,全名fourDirectionCheck

int dist[20][20];
int visited[20][20] = { 0 };

int queueX[400];//队列
int queueY[400];

int mark = 0;//用来标记已访问的格子，每次BFS都会更新一次，表示不同次调用时的"已访问"

int BFS(int startx, int starty, int destx, int desty, int block[20][20])
{
	if ((startx == destx) && (starty == desty))
	{
		return 0;//如果就是在同一位置，直接结束
	}
	
	//初始化队列
	int qhead, qtail;//因为本质上是两个队列并列进行，本质上是一个队列，所以只需要一套head和tail
	qhead = 0;
	qtail = 0;

	//压入队列
	queueX[qtail] = startx;
	queueY[qtail] = starty;
	qtail = (qtail + 1) % 400;

	mark++;
	visited[startx][starty] = mark;
	
	dist[startx][starty] = 0;

	while (qhead != qtail)//除非队列穷尽，否则一直进行下去
	{
		int tempx = queueX[qhead];
		int tempy = queueY[qhead];

		for (int i = 0;i < 4;i++)
		{
			int newx = tempx + fdc[i][0];
			int newy = tempy + fdc[i][1];

			
			if (newx < 0 || newx > 19 || newy < 0 || newy > 19)
			{
				continue;//在地图外，不算
			}
			else if (visited[newx][newy] == mark)
			{
				continue;//访问过了，不算
			}
			else if (block[newx][newy] == 1)
			{
				continue;//无法通行，不算
			}
			else if ((newx == destx) && (newy == desty))
			{
				int res = dist[tempx][tempy] + 1;
				return res;
			}
			else
			{
				dist[newx][newy] = dist[tempx][tempy] + 1;
				visited[newx][newy] = mark;

				queueX[qtail] = newx;
				queueY[qtail] = newy;
				qtail = (qtail + 1) % 400;
			}
		}
		qhead = (qhead + 1) % 400;
	}
	return -1;//找不到路径
}
```

这个算法的思想就是我从一个格子出发，向四周四个格子拓展

然后，当我们到达一个新的格子的时候，再从这个格子的四周拓展，直到我们用这种方法走到终点格

因为我们是边走边算距离，因此当我们走到终点的时候，可以直接返回距离
