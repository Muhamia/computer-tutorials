### 枚举

枚举是一种和结构体类似的数据存储方式

区别在于:枚举存储的是常量，而结构体可以存储变量

#### 定义
定义枚举数据类型:
enum 集合名{内容}；

例如
```C
enum months{JAN,FAB,...,DEC}
```

#### 初始化
默认来讲，枚举内的常量会从0开始初始化

如果规定了第一个常量是1，那么之后就是2 3 4...这样初始化

#### 创建枚举变量
enum 枚举名 变量名

这个枚举变量，默认存储的是第一个常量


实例:
```C

enum months{JAN=1,FEB,MAR,APR,MAY,JUN,JUL,AUG,SEP,OCT,NOV,DEC};
int main(void)
{
   enum months month;
   char * monthName[]={"","January","February","March",……};/*12个月名称略*/
   //因为我们定义JAN = 1，所以我们需要一个""作为占位符把0占了
   for(month=JAN;month<=DEC;month++)
   {
        printf("%2d,%11s\n",month, monthName[month]);
   }
   return 0;
} 
```

当然，上面这种写法并不常见，大家只是知道枚举数据能这么用就行
