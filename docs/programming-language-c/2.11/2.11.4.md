### 2.11.4 枚举

枚举是一种和结构体类似的数据存储方式

区别在于:枚举存储的是常量，而结构体可以存储变量

#### 定义
定义枚举数据类型:
enum 集合名{内容}；

例如
```C
enum months{JAN,FAB,...,DEC}
```

#### 枚举的应用

枚举的应用有很多，这里我们就用一个比较常见的状态管理来做例子
